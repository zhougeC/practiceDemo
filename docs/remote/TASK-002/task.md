### 2.1 技术约束（硬性）

- **纯静态**：不使用需要构建的框架；交付物本身零构建步骤。
- **第三方 3D 库必须本地化**：随仓库提供本地文件或单文件内联，**运行时不得依赖 CDN**。
- **`file://` 直接打开必须可运行**：不得依赖 `fetch`/`XHR` 读取本地文件（`file://` 下会失败）；
  不得依赖 ES module 的跨文件 import（`file://` 下受 CORS 限制），除非设计明确论证其可行性。
- **构建期允许**：可在 Mac 上一次性联网取库并 vendoring / 打包（npm + 复制构建产物，或 esbuild/rollup 打包），
  但产物必须是可直接打开的静态文件；**用户侧无构建**。
- 不得读取任何凭据、环境变量或私密配置；页面**不得发起网络请求**。
- 代码/资源总量保持合理（单个 HTML 或少量本地文件），不引入二进制大资源。
- 目标：桌面 Chrome 与常见移动端浏览器；**无 WebGL 时给出明确降级提示**。

### 2.2 库选型要求（重点，纠正上一版的一个错误前提）

- 上一版设计的推理是："VPS 无网络 + 仓库无 three.js ⇒ 自研渲染器"。**该前提不成立**：
  取库发生在 Mac 构建期，VPS 的网络限制**不能**作为选择自研渲染器的理由。
- 设计必须给出**本地文件库策略**，并显式比较（至少）：
  1. vendored three.js（说明具体版本、UMD 还是打包产物、是否要求 WebGL2、许可文件、体积）；
  2. 构建期打包（esbuild/rollup 把 three + 应用代码打成单文件）的可行性与代价；
  3. 自研最小渲染器（只有在给出可量化理由时才可选：如体积上限、WebGL1 兼容、交付约束）。
- 必须说明所选方案在 `file://`、无网络、移动端、无 WebGL 降级四种场景下的行为。

## 6. 已知缺陷类别（来自 TASK-001 的独立审计；**不是权威实现，不得照抄**）

上一版实现（`c78ba01…`）在独立审计中出现过下列类别的问题。TASK-002 的设计必须**显式**给出防御机制，
并在实施包中安排对应检查。禁止假设"这次不会发生"。

| 类别 | 现象 | 设计要求 |
|---|---|---|
| held input / 自动驾驶优先级 | A/D/Space/T 只在按下瞬间触发，未计入"用户活跃"，按住超过空闲阈值仍被自动驾驶接管 | 定义"用户活跃"的完整输入集合（含按住、指针、触屏），并给出打断/恢复规则 |
| 指针状态机 | 仅处理 `pointerup/pointercancel`；`lostpointercapture`/`blur` 未清理 → `dragId` 永久非空；单 `dragId` 被第二指覆盖 | 完整状态机 + 清理路径 + 多指模型 |
| 多点触控同按钮 | 同一按钮双指按下，任一抬起即释放 | 按 act 维护指针计数 |
| 页面隐藏/恢复 | `visibilitychange` 只重置时钟/音频，未清理输入；fatal 后恢复可见又无条件 `resume` | 隐藏即清理输入；fatal/ctxlost 状态下不得恢复音频 |
| 上下文丢失 | `webglcontextlost` 仅显示提示，未挂起音频；fatal 与 ctxlost 两层 overlay 叠加 | 统一降级状态机（fatal / ctxlost / 正常 三态互斥） |
| 顶点/片元不一致 | 顶点位移乘了近岸衰减，片元法线梯度未乘 → 近岸高光跳变 | 同一因子必须同时进入位移与法线，明确传递方式 |
| NaN 自愈 | 抽查步长 7 且只查位置不查速度 → NaN 持续污染 | 定义完整数值健康检查（位置+速度、步长、触发重置） |
| DPR 缓存 | `baseDPR` 只在启动读取，`resize` 不重算 | `resize`/画质切换时重算 |
| POV 时序 | 切 POV 立即隐藏头部，机位有阻尼延迟 → 可见无头鹈鹕 | 可见性切换与机位距离阈值绑定 |
| 着色器精度 | 硬编码 `precision highp float;` 在老移动 GPU 上编译失败 | 交由库注入或提供 mediump 回退 |
| 油门/刹车 | 两者代数相加，同时按住仍加速 | 定义明确的优先级（刹车优先） |
| 鱼的位置 | 渲染位置带正弦偏移，捕获判定用静态位置 → 画面偏离仍触发 | 单一变换源 |
| fatal 无恢复 | 任一帧异常即永久停机，无重试入口 | 定义错误分类、重试/重载入口 |

**再次强调**：以上只说明"这些地方容易错"，不构成设计建议，也不代表上一版实现可用作参考。
