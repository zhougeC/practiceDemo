### 2.1 Q-03 跳跃（真实 `PB.sim.step`，H=1/60，v0=5.0，g=14）

| 序 | 每步更新 | 最高点 | 滞空 | 步数 | AC-6c（0.863–0.923 / 0.684–0.744） |
|---|---|---|---|---|---|
| `vy_first`（修订前 §4.5.2 字面） | `vy −= g·h` 后 `y += vy·h` | **0.851667** | 0.700000 | 42 | apex **FAIL**（−0.01133） |
| `pos_first`（另一字面序） | `y += vy·h` 后 `vy −= g·h` | **0.935000** | 0.733333 | 44 | apex **FAIL**（+0.01200） |

- 一阶截断误差 `v0·h/2 = 0.0416667` > AC-6c 半宽 `0.03`；`M-09` 锁定 `H=1/60`（满足 AC 需 `h ≤ 0.012 s`），故两种字面序在冻结约束下**都**不成立。

### 2.2 Q-04 道具（真实 `InstancedMesh.instanceMatrix.array` 回读；**不读任何镜像**）

判据（ADR-21）与实测：

| 档位 | 非回绕样本 | 回绕 | ① `max |Δz_src − ΔS|` | ② `z_inst === Math.fround(z_src)` 违例 | ③ `max |Δz_inst − ΔS|` | ③ / 逐端点上界 | ④ `max |Δz_src − (ΔS − span)|` |
|---|---|---|---|---|---|---|---|
| S≈1e4 | 2979 | 1 | 0 | 0 / 59600 | 2.60576e−05 | 0.87400 | 0 |
| S≈1e6 | 2979 | 1 | 0 | 0 / 59600 | 2.60576e−05 | 0.87400 | 0 |
| S≈1e7 | 2979 | 1 | 0 | 0 / 59600 | 2.60584e−05 | 0.87400 | 0 |

- 域与量化步长（推导）：`z ∈ (−480, 20]` ⇒ `|z| < 480 < 512` ⇒ `ulp32 = 2^(8−23) = 2^−15 = 3.0517578125e−05`；单端 ½ulp ≤ `2^−16`，两端合计 ≤ **`2^−15`**。
- 逐帧预算：`Δz_inst − ΔS = (e_k − e_{k−1}) + (Δz_src − ΔS)`，`|e| ≤ ½ulp32` ⇒ `|Δz_inst − ΔS| ≤ ½ulp32(z_k) + ½ulp32(z_{k−1}) + 1e−6`。
- **字面 ±1e−6 套到矩阵**：三档全部 FAIL（2.6058e−05 > 1e−06）。这是 binary32 的表示精度下限，不是实现缺陷。
- 回绕：`z: +20 → −(span−20) = −480`，由 `floor((i·spacing − S)/span)` 的变化唯一判定；位移恒等于 `ΔS − span`（实测误差 0），回绕点满足 `z_{k−1} + ΔS > 20`。
- 绘制路径真实：`renderer.info.render.calls = 13`、`triangles = 2214`、`glVersion = 2`。

**裁决方对实施侧证据的两处勘误（已接受并落库）**
1. 实施侧在裁决请求中写的常数上界 `2^−14` 是笔误，正确值为 **`2^−15`**（单端 `½ulp ≤ 2^−16`，两端合计 `2^−15`）。实测 `2.6058e−05 < 3.0518e−05` 自洽。
2. `impl-notes.md` Q-04 与 `world.js` 旧注释写的"|z|≈500 m 处量化步长约 6e−5"属于 binade `[512,1024)`，本域（`|z| < 480`）取不到；正确值 `2^−15`。
