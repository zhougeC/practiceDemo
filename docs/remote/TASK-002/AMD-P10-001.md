## 1. 裁决

**Q-14：mode 1 / S3 的三条判据与机位互斥**
- **裁决**：
  - 采纳 (a)：S3 拆成 S3a（构图）和 S3b（夜灯）。
  - 采纳 (c)：p=0.50 的围巾取色从 S3 移除，取色只在 S1 判（AC-1b(i)）。
  - 采纳 (d)：S7 不再判飘带像素。
  - **(b) 必要但需用户批准**：在现行 MUST 机位下，S3a 的"下半 ≥40% 海面"经下文证明不可达。批准前 S3a 记为 BLOCKED-USER，不记 PASS。
- **依据**：
  - p=0.50 时任意法线的 V 上界为 0.186，小于 0.25，这是解析上界。
  - 灯头因视锥原因在 0/15360 帧入画。
  - 实测海面 2.52%。
  - S7 的飘带精确投影只有 82.5 px。

**下半海面不可达的证明**（现行 mode 1 机位，覆盖所有列与所有车道）：
- 记号：下俯角 θ=5.94°（sinθ=0.1035）；tanV=tan20°=0.3640；tanH=tanV·16/9=0.6471；a 为像素在下半画面中距中线的比例，a∈[0,1]。
- 像素射线的下俯角满足 `tanδ ≥ (sinθ + a·tanV·cosθ)/√(1+tanH²) = (0.1035+0.362a)/1.1911`。
- 射线要落到海面，必须在水平距离 D 内高度下降不超过 y_cam−SEA_Y：`tanδ ≤ (y_cam+0.8)/D`。
- 相机 x = 车x − 10 ≤ −7.5，所以到岸线的 D ≥ 15.93+7.5 = 23.43。
- 取 y_cam ≤ 3.2（车包围盒中心 y ≤ 1.0 再加 2.2），得 a ≤ (1.1911·4.0/23.43 − 0.1035)/0.362 = **0.276**。
- 结论：下半画面中海面占比 ≤ **27.6% < 40%**。这与 S、光照、实现都无关，是 MUST 机位下的几何上限。

**Q-15：S6/S12 的 −90° 环绕被棕榈带遮挡**
- **裁决**：保留 −90°，在 S6/S12 行注明"主体可能被 x=−8 的棕榈带遮挡，主体可见性不作本图判据"。默认环绕 yaw 已经是 35°，落在海侧（sin35°>0，相机 x>0），不用改。本项只涉及 §5.3 层面，不触及 AC-8a（mode 4 由 S14 判）。PALM_X 不变。
- **依据**：S6/S12 判的是海面，S6 检出泡沫带 10 条，S12 逐列跳变 0.27–0.41/255，均已满足；头盔投影与掩膜一致，说明遮挡来自树干。

**Q-16：HUD 内联样式迁入 css/style.css**

### 5.1 Q-14 判据 (a)：现行 mode 1 的「下半 ≥40% 海面」不可达 —— **结论一致，数字更严**

**证明思路（比裁决方更直接）**：射线要首次命中海面，必须在到达岸线 `x = SHORE_X = 15.92857` 之前不与地面相交。
地面上折点只有 `x=ROAD_HALF`（`y=0`）与 `x=SHORE_X`（`y = SEA_Y`），且在两者间单调下降，故必要条件为

```
tanδ ≤ (C_y − y_surface) / (SHORE_X − C_x)        … 相机在岸线以西时（C_x < SHORE_X）
```

下半幅内 `tanδ(nx, ndc_y)` 随 `ndc_y` 由 0 → −1 严格单调递增，因此"满足必要条件的竖向测度 / 幅高"是该幅内海面占比的**严格上界**，
且逐列二分定位临界 `ndc_y` 是精确的（无网格误差）。

| 车道 x | 相机 | 下半海面**实测** | 严格上界（均海面 y=−0.8） | 严格上界（波谷 y=−1.375，最宽松） |
|---|---|---|---|---|
| −2.5 | (−12.50, 2.2, 1.5) | 0.944% | **2.33%** (`tanδ ≤ 0.10553`) | 8.18% (`tanδ ≤ 0.12575`) |
| 0.0 | (−10.00, 2.2, 1.5) | 2.587% | **5.28%** (`tanδ ≤ 0.11570`) | 11.68% (`tanδ ≤ 0.13788`) |
| +2.5 | (−7.50, 2.2, 1.5) | 5.345% | **8.84%** (`tanδ ≤ 0.12805`) | 15.91% (`tanδ ≤ 0.15259`) |

- 结论：即使把波浪波谷当成海面（最宽松口径），上限也只有 **15.91% < 40%**，缺口 ≥ 24.1 个百分点；与 `S`、光照、实现无关。
- **与裁决方数字的差异**：裁决方写"上限 27.6%"，其推导式

  `tanδ ≥ (sinθ + a·tanV·cosθ)/√(1+tanH²)`，取 `a=1` 得 0.3908

  **不成立**：(i) 在 `nx=0` 处，下边射线的下俯角精确等于 `tan(θ + FOV/2) = tan(25.937°) = 0.4864`（脚本实测同值），
  而该式给出 0.3908；(ii) 不等式方向也反了——到达更远的岸线需要**更平缓**的射线（`tanδ ≤` 上界），不是更陡。
  两者都不影响"不可达"这一结论，但 §3 里 ADR-33 的"27.6%"引用的是不成立的式子。
  **建议替换为 15.91%（波谷口径，最宽松）或 8.84%（车道 +2.5 的均海面口径）**，并给出上面那一行必要条件。
- 逐像素反证：在下半幅 400×400 网格内穷举，命中海面的像素共 4,138 个，其 `tanδ` 最大值 **0.11565 ≤ 0.11570**（违例 0 个），
  与必要条件自洽。

- **灯头结构性不入画**：`z` 以 0.5 m 步长扫 (−460, 20] 的全部 960 个位置 × 3 条车道（2,880 次投影），

### 5.3 Q-14 判据 (c)：围巾取色 —— **结论一致**

   (b) `y=0.6` 必须是**世界绝对高度**（若按"车中心+0.6"读作 1.6，车道 −2.5 变 23.8% FAIL）；
   (c) 接受 mode 1 里车只有约 1/11 画面高（AC-1a 的跨度判据属 mode 0/S1，不受影响）。
   若不批准：现行机位下 S3a 不可达（上限 8.84% / 15.91%），只能由用户重新定义"侧视"镜头中海面应占的期望；
   本草案**不改任何数字**，S3a 保持 `BLOCKED-USER`。
2. **ADR-37（L 的口径）** —— 决定 AC-1b(iii) 的计数口径。批准前墨镜分项记 `PENDING-USER`
   （现有实测 404 dark / 230 feather 是该口径下的读数）。这一条**不改变用户看到的产品**，只影响判据口径，
   但按"触及 AC 定义"的纪律仍然回退给用户。

## 11. 与裁决方不一致之处（实施侧复算结论；前 3 条须在应用前修正，后 2 条只影响表述）

| # | 裁决方 | 实施侧复算 | 影响 |
|---|---|---|---|
| 1 | ADR-33：「现行 mode 1 的海面占比几何上限为 **27.6%**」，推导式 `tanδ ≥ (sinθ + a·tanV·cosθ)/√(1+tanH²)` 取 a=1 得 0.3908 | 该式在 `nx=0` 处给出 0.3908，而精确值是 `tan(θ+20°) = 0.4864`；且必要条件的方向是 `tanδ ≤`（越远越需平缓）。**正确上限：8.84%（均海面）/ 15.91%（波谷）** | 「不可达」结论不变，但引用的数字与推导必须换掉，否则第三方复算会对不上 |
| 2 | ADR-34：`pos=(车x+21, 0.6, 车z−22)` | 车道 −2.5 只有 **26.2% < 40%**；dx=**23** 时三条车道 **47.7 / 66.2 / 75.0%** | 批准前必须定 dx；否则换道取证会随机跌破判据 |
| 3 | ADR-34：`0.6`（未写明口径） | 世界绝对高度 ⇒ 47.7/66.2/75.0%；车中心+0.6 ⇒ **23.8/42.2/57.2%** | 同一条 ADR 在两种读法下结论相反，必须写死口径 |

另有两处**理由**需要更正（结论本身可接受）：

| # | 裁决方/前任理由 | 实测 |
|---|---|---|
| 4 | "S7 的飘带像素在 mode 1 不可达（82.5 px）" | 精确投影 **169.2 px²**，`app-gates.json` 实测 **180 px ≥ 150** ⇒ 现行 mode 1 下可达且已达成；S7 改判的正当理由是**判据重复**，不是不可达 |
| 5 | "S6/S12 的主体完全不可见" | 遮挡是**随 S 变化**的：S6 至少一处被挡 11%、全部被挡 2%；S12 各 4%。应表述为条件性遮挡，不是完全不可见 |

### 13.2 ADR-34 的 `dx` 与 `y`：独立复算定值

复算脚本：`tools/e2e/adr34-projection.mjs`（不读应用源码，常量逐字抄自 `config.js` 与 `plan.md` §1.1/§1.3/§4.7；
1080p、FOV 40、竖直 FOV、`aspect = 16/9`）。另一条独立实现（分段线性精确求交）用于交叉核对，两条实现逐位一致。

**判据（同时满足才可用）**：三条车道（−2.5 / 0 / +2.5）的下半海面都 ≥40%；车包围盒中心 `|ndc_x| ≤ 1/3`；
车高 ≥90 px；整车 8 角不出画；相机 y ≥ `camFloor(x)`。

| dx | y 口径 | 车道 −2.5 | 车道 0 | 车道 +2.5 | 车高 px | 结论 |
|---|---|---|---|---|---|---|
| 20 | 绝对 0.6 | 16.0% | 46.4% | 66.8% | 101.2 | 车道 −2.5 FAIL |
| 21 | 绝对 0.6 | **26.2%** | 55.5% | 70.2% | 98.9 | 车道 −2.5 FAIL（与 §5.5 一致） |
| 22 | 绝对 0.6 | 36.8% | 61.7% | 72.9% | 96.6 | 车道 −2.5 FAIL |
| **23** | **绝对 0.6** | **47.7%** | **66.2%** | **75.0%** | **94.4** | **PASS（最小可行 dx）** |
| 24 | 绝对 0.6 | 56.0% | 69.6% | 76.8% | 92.3 | PASS |
| 25 | 绝对 0.6 | 61.8% | 72.3% | 78.3% | 90.2 | PASS（车高刚好 90） |
| 26 | 绝对 0.6 | 66.1% | 74.5% | 79.6% | 88.1 | 车高 FAIL |
| 23 | 车中心+0.6 = 1.6 | **23.8%** | 42.2% | 57.2% | 94.4 | 车道 −2.5 FAIL（与 §5.5 一致） |

**定值**：`dx = 23`、`y = 0.6`（**世界绝对高度**）、`z = 车z − 22 = −22`、注视点 `(车x, 0.6, 7)`、FOV 40、k 4、near 0.1。
三条车道 `ndc_x = 0.233`、`ndc_y = 0.034`、车高 94.4 px、包围盒最远角 `|ndc| = 0.268`（整车在画内）。

**为什么不是 21**：21 在车道 −2.5 只有 26.2%（余量 −13.8 pp），换道取证会随机跌破判据。
**为什么不是 24/25**：24 车高 92.3 px、25 车高 90.2 px 已贴住 90 px 下限，余量收益递减；23 在满足判据的三个取值（23/24/25）中
**车高余量最大**（94.4 px，比下限高 4.4 px），同时三条车道的海面余量已 ≥7.7 pp（47.7/66.2/75.0 vs 40）。
**为什么必须写死"世界绝对高度"**：同一串数字在"车包围盒中心 +0.6（=1.6）"的读法下车道 −2.5 变 23.8%，
判据结论相反（§5.5 已指出）。
