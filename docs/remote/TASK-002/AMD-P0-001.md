两条 `console.error` 的逐字原文（来源 `vendor/three.min.js` line 3798 col 24258 → 源码 `three.module.js:29373` 的 `onContextCreationError`）：

```
THREE.WebGLRenderer: A WebGL context could not be created. Reason:  disabled by enterprise policy or commandline switch
THREE.WebGLRenderer: A WebGL context could not be created. Reason:  Failed to create a WebGL2 context.
```

关键机制（决定 `Q-02` 的解法）：Chromium 对**一次**失败的 `canvas.getContext('webgl2', attrs)` 派发两个创建失败事件；**浏览器自身不写 console**，两条 error 完全由 three 的监听器产生。因此「应用先建上下文、再把 `context` 传给 `WebGLRenderer`」可在**不过滤任何日志**的前提下让 error 归零。
