
## 4. 出口门禁（P0 全部判据）

### 4.1 `[build]` §5.7 全部（PR-2）

1. `vendor/three.min.js` ≤ 800 KB（819,200 B）。
2. `grep -c sourceMappingURL vendor/three.min.js` = 0。
3. 输出以 `var THREE=` 开头，不含顶层 `import`/`export`。
4. `vendor/VERSION.txt` 记录：three 版本（0.162.0）、esbuild 版本、node 版本、输入 `three.module.js` 的 sha256、输出 sha256 与字节数、完整命令。
5. `vendor/three.LICENSE` 存在（源自 `node_modules/three/LICENSE`）。
6. 不提交任何 `node_modules`、不提交 Playwright 浏览器；交付页面不引用 `tools/` 下任何文件（P0 无交付页面，P1 起适用）。

### 4.2 `[browser]` 冒烟（PR-2、PR-3）

1. `tools/three-smoke.html` 在默认 Chromium 中：`THREE.REVISION === '162'`，`isWebGL2 === true`，实际渲染出立方体（`renderer.info.render.triangles > 0` 且读取到实际像素）。
2. 页面发出的**非 `file://` 请求数 = 0**（`plan.md` §5.3 / AC-9a 的构建期口径）。
3. Chromium 以 `--disable-webgl2` 启动，冒烟页按 plan §4.11 预创建上下文：`isWebGL2 === false`、`gl.getParameter(gl.VERSION)` 以 `WebGL 1.0` 开头、`!(gl instanceof WebGL2RenderingContext)`、三角面 = 12、非背景像素 > 0（真实 WebGL1 路径；判据不看 flag 名，ADR-20）。
4. 两个场景都满足 plan §5.4 第 2 条的 Console 判据：error 和 pageerror 均为 0，不设白名单；warning 逐条记录（WebGL1 场景预期有 1 条 r162 弃用 warning）。
5. PR-3 的 `ANGLE_instanced_arrays` 覆盖：记录真实 WebGL1 下 `gl.getExtension('ANGLE_instanced_arrays')` 与 `renderer.extensions.has('ANGLE_instanced_arrays')` 的实测值。**能力屏蔽（把 `getExtension` 置空）只作为单独标注的模拟场景**，不得当作"硬件缺失"证明；若在可用设备上无法取得真实"无该扩展"的 WebGL1 环境，记 **NOTVERIFIED**，不得记 PASS（`handoff.md` H-4、`plan.md` §5.6）。
