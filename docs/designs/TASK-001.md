## 设计正文（远程 `.result` 原文）

## TASK-001 实施计划：鹈鹕海岸公路

### Context

仓库目前只有 Java/Maven 示例，没有任何前端代码、本地 3D 库或静态资源。本任务新增一个可直接以 `file://` 打开的 3D 互动页面，同时保持现有 Java 工程不变。

环境禁止运行时 CDN、网络请求和构建步骤。仓库内也不存在可复用的 three.js 文件，因此推荐**自研小型 WebGL 1 渲染器**，用程序化几何与着色器实现全部画面。这样没有第三方依赖、无需读取本地模块文件，也不会触发 `file://` 下的模块 CORS 问题。

### 交付文件

| 文件 | 内容 |
|---|---|
| `index.html` | 入口；内联 CSS/JS、全部程序化资产，无外部请求 |
| `docs/designs/TASK-001.md` | 架构、视觉方案、物理参数、控制/成就/镜头说明、验收映射 |
| `docs/reviews/TASK-001.md` | 独立静态审计：逐条证据、代码风险、控制台/离线检查、人工体验待办 |

不修改 Java 模块，不新增构建配置或二进制资源。目标 `index.html` < 300 KB，代码保持分区清晰。

### 实现设计

#### 1. 渲染基础

- 使用 WebGL 1 + GLSL ES 1.00，兼容桌面 Chrome 与常见移动端；不使用需要扩展的渲染特性。
- 内联经典 `<script>`，不使用 ES module。
- 自建最小数学库（Vec3/Mat4、damp、clamp、确定性噪声）与 GPU 网格抽象；所有几何由代码生成。
- 通用不透明对象着色器：方向光 + 环境光、雾、顶点色、昼夜光照、可选双面渲染。
- 独立绘制通道：
  - 全屏天空着色器：天空渐变、云带、太阳、月亮、程序化星空。
  - 海面着色器：顶点波浪、解析法线、菲涅尔、日月高光、岸边碎浪。
  - 粒子通道：抓鱼火花、速度流线和夜萤效果。
- 低多边形风格 + 程序化海浪/天空，避免依赖贴图资源。

#### 2. 场景与角色

- 三车道海岸公路：柏油路面、滚动虚线、护栏、反光柱、左侧草坡与棕榈/柏树、礁石、右侧悬崖与海滩、远处灯塔。
- 场景元素按速度循环回收，营造无限前进；近景车道贴图、护栏柱和浪花提供速度感。
- 鹈鹕自行车模型：
  - 双轮、车架、车把、座椅、曲柄/脚踏、前车篮、动态轮辐。
  - 鹈鹕身体、弯曲长颈、大头、长黄色喙与橙色喉囊、黑框墨镜、带通气槽的头盔与下颌带、红围巾。
  - 翅膀/手臂连接车把；`T` 时展开翅膀并抬起前轮。
  - 踩踏、身体起伏、头部微动、转弯倾斜、跳跃与落地压缩。
- 抓鱼时增加颈部前探和喉囊抖动；车篮中最多展示 3 条已抓到的鱼。
- 使用假接触阴影增强落地感，不引入阴影贴图成本。

#### 3. 围巾布料物理

- 两条红色围巾尾，每条使用约 `3 × 10` 粒子网格。
- Verlet 积分 + 距离约束 + 顶部锚点固定；固定小步长、限制最大子步数与迭代次数。
- 力场：重力、随车速增强的相对气流、侧向风、正弦湍流。
- 转向、跳跃、头部动作作为伪惯性力传入；锚点随颈部运动，使围巾自然滞后、抖动、回摆。
- 每帧更新动态顶点缓冲与法线，双面渲染；预分配数组，避免每帧大量 GC。
- 风速随车速变化，高速时围巾明显拉直，减速后回落。

#### 4. 昼夜、天空与海洋

- 约 120 秒自动循环：黄昏 → 日落 → 暮色 → 月夜 → 黎明 → 白天 → 黄昏；起始为黄昏，约 30 秒内进入星空月夜。
- 天空着色器按阶段插值天顶/地平线颜色、太阳高度、月亮位置、星星透明度、云层亮度。
- 太阳与月亮为程序化圆盘和光晕；夜间显示多尺度闪烁星空，白天隐藏。
- 方向光、雾色、环境光随阶段变化；夜间亮起车头灯与护栏反光。
- 海面：
  - 多层方向正弦波叠加位移，解析计算法线。
  - 菲涅尔混合海色与天空色，太阳/月亮反射路径随昼夜切换。
  - 近岸高频波带、白浪噪声、岸边冲刷泡沫与浪花高光。
  - 海面整体覆盖海岸远处，与天空雾色融合。

#### 5. 玩法、控制与自动驾驶

- 状态：速度、目标车道、横向弹性、跳跃高度/速度、抬轮计时、里程、得分、连击、抓鱼统计。
- 键盘：
  - `W/S` 加减速；
  - `A/D` 变道；
  - `Space` 跳跃；
  - `T` 展翅抬前轮；
  - `C` 或镜头按钮切换镜头；`1–5` 可直选；
  - `H` 成就列表，`M` 静音。
- 鱼在三条车道中生成，带发光环、摆动尾鳍和上下浮动；金鱼额外加分。
- 同车道且距离进入捕获窗口时自动抓鱼，播放颈部前探、粒子、加分与连击；漏鱼重置连击。
- 自动巡航：5 秒无输入后启用，自动选择最近鱼所在车道、调整速度并抓鱼；任意键盘、触屏按钮或画布拖动立即打断。
- 触屏：
  - 左/右变道；油门、刹车、跳跃、展翅；
  - 顶部镜头、成就、声音按钮；
  - Pointer Events 支持多点按住与释放，正确处理 `pointercancel`。

#### 6. 五种镜头

| 镜头 | 行为 |
|---|---|
| 追尾 | 平滑跟随，随速度轻微扩大 FOV，跳跃/高速震动 |
| 海岸侧视 | 左侧高位追踪，海洋与日落在背景 |
| 电影运镜 | 定时切换前侧低机位、侧向跟拍、俯视等镜头并平滑移动 |
| 鹈鹕主观 | 头部视点，隐藏头部/眼镜/头盔，保留喙与车把，带踩踏摆动 |
| 自由环绕 | 鼠标/触摸拖拽环绕，滚轮/双指缩放，空闲时缓慢自转 |

镜头通过 `C`、触屏按钮切换；追踪所有已使用镜头。

成就面板显示名称、锁定/解锁状态、提示和进度；解锁时弹出队列 Toast 并播放合成提示音。

| 2 | 鱼贯而入 | 累计抓 10 条 |
| 3 | 海岸美食家 | 累计抓 30 条 |
| 4 | 五连抓 | 连续抓 5 条不中断 |
| 5 | 疾风骑士 | 达到 50 km/h |
| 6 | 空中越浪 | 跳跃 5 次 |
| 7 | 展翅高飞 | 完成 3 次展翅抬轮 |
| 8 | 夜航者 | 进入夜晚阶段 |
| 9 | 月下捕鱼 | 夜间抓到鱼 |
| 10 | 仰望星空 | 夜晚自由镜头抬头保持 3 秒 |
| 11 | 五镜导演 | 使用全部 5 种镜头 |
| 12 | 海岸长骑 | 累计骑行 1000 m |

进度为本次会话内有效，不写入 localStorage，避免 `file://` 存储差异。

#### 8. WebAudio 音频

- 首次键盘或触摸交互后创建/恢复 AudioContext，无自动播放报错。
- 无外部音频；全部实时合成：
  - 海浪环境噪声、随速度变化的风声；
  - 合成鼓、低音、琶音与铺底和声；
  - 节拍由曲柄角度触发，节奏直接跟随踏频；
  - 抓鱼、跳跃、展翅、变道、成就、夜间氛围音效。
- 静音按钮与 `M` 键；所有音频调用捕获异常。

#### 9. UI、画质自适应与降级

- HUD：速度、得分、连击、鱼数、里程、昼夜阶段、成就计数、镜头名称、自动巡航状态、音频状态。
- 成就抽屉、Toast、桌面按键提示与移动端虚拟按钮；CSS 使用安全区内边距。
- 自适应画质：
  - 统计滚动平均帧时间；
  - 分级调整渲染分辨率倍率（约 `0.55–1.0 × DPR`）、粒子数量和星空/特效细节；
  - 带冷却与滞回，避免频繁升降；HUD 显示当前画质。
- 无 WebGL 时显示明确的中文降级提示并隐藏游戏 UI；上下文丢失时显示恢复提示。
- 捕获初始化和主循环异常，避免未捕获异常反复刷控制台。
- 通过 CSP meta 禁止网络连接：`default-src 'none'`，仅允许内联脚本/样式与 data 图标。
- 暴露只读调试快照 `window.__pelicanDemo.getState()`，并提供测试用镜头/昼夜/刷鱼辅助接口，方便人工验收和审计。

### 主要风险与规避

- **自研渲染器成本**：保持 WebGL1、低多边形和固定管线式着色器，避免阴影贴图与后处理。
- **布料不稳定**：小固定步长、限制子步、阻尼和最大位移约束；异常时退化为静态围巾，不影响主循环。
- **移动端性能**：限制绘制调用与粒子数，DPR 上限 2，动态分辨率优先。
- **file:// 限制**：所有资源内联、无 fetch/module、无存储依赖。
