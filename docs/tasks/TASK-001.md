# TASK-001：鹈鹕海岸公路 3D 交互页面

## 目标
在仓库根目录生成可直接本地打开的 3D 交互页面（`index.html`，可附带本地静态资源），
用户双击/直接打开后无需构建、无需本地服务器即可体验。

## 功能契约（全部为验收项）
1. 鹈鹕骑自行车，戴头盔与墨镜，脖子系红围巾；海岸公路场景。
2. 围巾为布料物理模拟（wind + inertia，能飘动、滞后、抖动）。
3. 昼夜循环：黄昏 → 星空月夜，含太阳/月亮、天空渐变、星星、海面反光变化。
4. 海面波浪与岸边碎浪（程序化动画/着色器）。
5. 鹈鹕可以抓鱼（鱼出现、被抓到、计分/成就）。
6. 控制：
   - W/S 加减速；
   - A/D 变道并抓鱼；
   - 空格跳跃；
   - T 展翅抬前轮。
7. 14 个成就，可解锁、有提示与列表。
8. 5 种镜头：追尾、侧视/远景、电影运镜、鹈鹕主观视角、自由/环绕（至少 5 种且可切换）。
9. 音频：浏览器实时合成的音效与音乐，节奏跟随踏频（WebAudio，无外部音频文件）。
10. 触屏按钮控制（移动端可用），与键盘并存。
11. 按帧率自适应画质（动态降/升分辨率或特效）。
12. 不操作时自动驾驶追鱼（自动转向/变道/抓鱼，仍可被输入打断）。

## 技术约束
- 纯静态：不使用需要构建的框架；第三方 3D 库必须随仓库提供本地文件或以单文件内联，**不得依赖运行时 CDN**。
- 直接以 `file://` 打开必须可运行；不得依赖 fetch/XHR 读取本地文件（file:// 会失败）。
- 不得读取任何凭据、环境变量或私密配置；不得发网络请求。
- 代码/资源总量保持合理（单个 HTML 或少量本地文件），不引入二进制大资源。
- 目标桌面 Chrome 与常见移动端浏览器；无 WebGL 时给出明确降级提示。

## 交付
- `index.html`（入口，可直接打开）
- 必要的本地静态资源（如本地 three.js 文件）
- `docs/designs/TASK-001.md`（设计结论）
- `docs/reviews/TASK-001.md`（独立审计结论）

## 验收
- 逐项对照上述 12 条功能契约，能在本地直接体验。
- 无控制台未捕获异常；帧率自适应生效；触屏按钮可用。
- 远程审计只审查代码并给出证据，不替代人工体验。
